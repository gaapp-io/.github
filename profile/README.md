# Gaapp.io

Goal planning from year to day. One yearly goal, broken down to quarter, month, week and today's step, so every day shows which bigger goal it serves.

Live since 2026-09-11 at [gaapp.io](https://gaapp.io), in [English](https://gaapp.io) and [German](https://gaapp.io/de). Built in public by [Tristan Eilenburg](https://github.com/mrb2beast).

## What's in the app

- Goal chain from year to day, with progress rolling up to the yearly goal
- Calendar week view, goal templates, SMART assistant for yearly goals
- Shared spaces for teams and coaches, with permissions per member
- AI planner that drafts a plan from a goal
- Analytics, dark mode, keyboard shortcuts
- REST API with personal API keys on paid plans, and an MCP server at `gaapp.io/mcp` with OAuth: list spaces, list goals, create a goal, check a goal off
